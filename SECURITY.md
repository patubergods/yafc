# Security

YAFC modifies a vehicle's SYNC 3 unit and its rear camera path. It is an unofficial hobby project
with no warranty and no support promise; see [docs/DISCLAIMER.md](docs/DISCLAIMER.md).

## Reporting a vulnerability

Use GitHub's private reporting: open the repository's **Security** tab and choose **Report a
vulnerability**. Do not open a public issue for a vulnerability. Ordinary bugs, install failures
and wrong camera pictures go through the
[bug report form](https://github.com/patubergods/yafc/issues/new/choose) instead.

Describe what you found, how to reproduce it, and which release you used. Do not include your VIN
or other personal data. No response time is promised.

## What is in scope

The installer, the dispatcher, the slot library and the HMI fragments in this repository. Ford's
software, the FMods jailbreak and other third-party mods are not part of this project; report
problems with them to their owners.
